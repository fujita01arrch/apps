HTML Apps 公開環境 — 使い方

自分たちで作ったHTMLアプリ（社内ツールなど）を、インターネット上で誰でも開けるページとして公開するための仕組みです。プログラミングやコマンド操作の知識は不要で、Claudeに「このアプリを公開して」と頼むだけで使えます。この説明書は Project/_html-apps フォルダの中に置いてあります。

これは何のためのもの？

PCの中にあるHTMLファイル（アプリ）は、そのままではPC内でしか開けません。この仕組みを使うと、そのアプリに専用の「URL（インターネット上の住所）」が発行され、スマホやほかのPCからでも開けるようになります。今後アプリを何本作っても、同じ場所に追加していくだけで済むように作られています。

できたもの

公開URL
https://fujita01arrch.github.io/apps/
↑ここを開くと、公開中のアプリの一覧が見られます
保管場所
Project/_html-appsフォルダ（このPC内）
公開先
github.com/fujita01arrch/apps
↑「GitHub」という、世界中で使われているファイル保管・公開サービス。今回はPublic（誰でも見られる）設定で作成

アプリを追加・更新したいとき

やることはとてもシンプルです。Claudeとのチャットで、以下のように伝えるだけで、あとの作業はClaudeが行います。

新しいアプリを
公開したい
「G:\...\〇〇アプリ.htmlというアプリを公開して」
→ Claudeが内容を確認し、一覧ページにも追加してくれます
すでに公開した
アプリを更新したい
「〇〇アプリを新しいファイル（G:\...\〇〇アプリ_v2.html）に更新して」
→ 内容を入れ替えて、同じURLで最新版に更新してくれます
  • アプリの中に顧客情報や社外秘の情報が含まれていないか、Claudeが公開前に確認します。心配な点があれば先に説明があるので、その指示に従ってください
  • アプリがGoogleログインや外部サービスの設定情報を含む場合、安全のため一部の操作をご自身にお願いすることがあります（その場合も、Claudeが「ここをクリックしてください」と具体的に案内します）

用語かんたん解説

この説明書や作業中に出てくる言葉の意味です。普段は覚える必要はありません。

GitHub
ファイルを保管し、インターネット上に公開できる世界的なサービス（Google DriveのようなもののIT開発者向け版）
リポジトリ
GitHub上の「保管フォルダ」のこと。今回はappsという名前で作成
Public（パブリック）
「誰でも見られる」設定。無料でアプリを公開するにはこの設定が必要（個人情報・社外秘を置かない前提）
push（プッシュ）
PC内の変更をGitHubに送って反映させる操作。これをすると自動的に公開ページが更新される

運用上の注意

  • Public（誰でも見られる）設定のため、個人情報・社外秘を含むアプリはここに置かない
  • 特定のアプリだけ非公開にしたい・別管理にしたい事情が出てきたら、その時点でClaudeに相談して切り出す
  • アプリ自体の制作は普段どおり Project/{日付}_{アプリ名}/00_original〜03_output で行い、完成したものだけをここに公開する
