HTML Apps 公開環境 — 使い方

複数のHTMLアプリをGitHub Pagesで公開するための環境です。この説明書は Project/_html-apps フォルダ直下に置いてあります。

できたもの

リポジトリ
github.com/fujita01arrch/apps（Public）
公開URL
https://fujita01arrch.github.io/apps/
ローカル場所
Project/_html-apps（git管理下、GitHubと同期済み）
自動デプロイ
mainブランチにpushすると.github/workflows/deploy.ymlが自動でGitHub Pagesにデプロイ
動作確認
sampleアプリで実際に公開されることを確認済み

新しいアプリを追加する方法

  1. Project/_html-apps/apps/<アプリ名>/index.html を作成する
  2. Project/_html-apps/apps/index.html の一覧に1行リンクを追記する
  3. git add → git commit → git push
cd Project/_html-apps
git add .
git commit -m "アプリ名を追加"
git push

これだけで https://fujita01arrch.github.io/apps/<アプリ名>/ に自動公開されます（手順は Project/_html-apps/README.md にも記載）。

運用上の注意

  • Publicリポジトリなのでソースコードも公開されます。個人情報・社外秘を含むアプリはここに置かないこと
  • 特定のアプリだけ後で単独リポジトリに分離したくなった場合は、その時点で切り出す運用とする（README記載済み）
  • 実際のアプリの制作は普段どおり Project/{日付}_{アプリ名}/00_original〜03_output で行い、完成したら _html-apps/apps/ にコピーしてpushする流れ
